# Refactor Log — تصمیمهای ریفکتور UI

این فایل تاریخ تصمیمها و دلیل آنها را نگه میدارد.

## 2026-10-21

### تصمیم: رنگ برند
- انتخاب: `#D95D32` (brand-600) برای light، `#EE8A66` (brand-400) برای dark.
- دلیل: کنتراست WCAG AA روی پسزمینهی سفید در light. در dark روشنتر شدن رنگ، کنتراست را حفظ میکند. حفظ هویت نارنجی برند.

### تصمیم: Neutral palette
- انتخاب: مقیاس گرم (Stone).
- دلیل: مقیاس سرد (`#F8F8F8`, `#C0C0C1`, ...) حس اداری و خشک میداد. گرم آن، حس «رسمی ولی صمیمی» میدهد.

### تصمیم: پایهی تایپوگرافی
- اندازهی body: `14px` (نه `16px`).
- line-height body: `1.9`.
- دلیل: فارسی به خط بلندتری برای خوانایی نیاز دارد. `14px/1.9` استاندارد فارسی UI است (نگاه: دیجیکالا، ترب).

### تصمیم: Radius
- انتخاب: `sm=6`, `md=10`, `lg=14`, `xl=20`.
- دلیل: یکپارچگی بین دکمه و کارت. `10px` برای دکمه حس مدرن و نرم میدهد بدون اغراق.

### تصمیم: Shadow
- انتخاب: چهار سطح (`xs`, `sm`, `md`, `lg`) با آلفای کم.
- دلیل: زیباییشناسی مینیمال و رسمی. سایههای موجود (مثل `0 10px 15px`) خیلی سنگین بودند.

### تصمیم: حذف dark override در variantها
- انتخاب: هیچ `dark:*` در `buttonVariants` و `inputVariants`.
- دلیل: رنگ در dark از CSS var میآید. تکرار `dark:*` باعث انحراف از SSOT میشد.

### تصمیم: حذف `colors.primary` و `colors.secondary` از palette
- دلیل: تکرار `brand` و `neutral`. SSOT یعنی فقط یک منبع برای هر رنگ.

### تصمیم: حذف `chart-*` از theme
- دلیل: در پروژه استفاده نمیشد. اگر بعداً لازم شد، بهعنوان `chart-1..5` اضافه میکنیم.
